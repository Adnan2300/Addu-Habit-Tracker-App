# Habit & Activity Tracker (Mobile PWA)

A Progressive Web App optimized for iPhone and desktop.

## Features
- 📅 **Month-Separated Activity Heatmaps**: Scrollable heatmaps per month.
- 🕒 **Live Clock & Date**: Displays the current local date and live time.
- ➕ **Modal Habit Creation**: Floating `+` action button launches a modal dialog to create habits.
- 📊 **Popup Analytics Suite**: Bar charts, line graphs, and pie charts inside a separate visual modal.
- 🔍 **Discrete Filter Bar**: Minimalist search input and category picker.
- 📱 **iPhone / Mobile Optimized**: Supports notch safe areas, smooth touch-scrolling, and PWA standalone mode.
